# Dependencies for the Streamlit Community Cloud deployment.
#
# Community Cloud searches the entrypoint's own directory for a requirements file BEFORE the
# repository root, so this file wins over the repo's requirements.txt. That is deliberate: it
# keeps jupyter, nbconvert, gradio, matplotlib, seaborn, scikit-learn, scipy, pandas and
# iterative-stratification out of the build. None are imported by the serving path
# (deploy/streamlit_app.py -> src.predict / src.viz -> src.config).
#
# CPU-only torch. The default PyPI Linux wheel bundles CUDA (~2.5GB), which would be a slow,
# fat build for no benefit on a CPU container. `==2.13.0` matches the CPU index's `2.13.0+cpu`
# (PEP 440 treats a local version as the higher match), so pip prefers the CPU wheel here while
# the same line still resolves on macOS for local testing.
--extra-index-url https://download.pytorch.org/whl/cpu

torch==2.13.0
transformers==5.14.1
numpy==2.5.1
streamlit==1.60.0
